# HealthDesk - Clinic Management System
## About the Project
HealthDesk is a desktop application developed in C# (.NET) using Windows Forms, designed to streamline clinic management processes. The system supports patient registration, appointment scheduling, and secure data handling.
### Key Features
* Patient registration with data validation (including PESEL number verification).
* Appointment and schedule management.
* Local data saving and loading system in JSON format.
### Technologies
* Language: C#
* Framework: .NET / Windows Forms
## O projekcie
HealthDesk to aplikacja desktopowa stworzona w języku C# (.NET) przy użyciu technologii Windows Forms, zaprojektowana w celu usprawnienia zarządzania przychodnią lekarską. System wspiera rejestrację pacjentów, zarządzanie wizytami oraz bezpieczne przechowywanie danych.
### Główne funkcjonalności
* Rejestracja pacjentów z walidacją danych (m.in. numer PESEL).
* Zarządzanie wizytami i harmonogramem.
* Lokalny system zapisu i odczytu danych w formacie JSON.
### Technologie
* Język: C#
* Platforma: .NET / Windows Forms
